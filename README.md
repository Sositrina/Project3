# Магазин
## Описание:
Содержит категорию товаров, название продукта, описание, цену и количество

## Функциональность:
- **Category** – Класс, представляющий категорию товаров в магазине  
- **Product** – Класс, содержащий название продукта, описание, цену и количество  
- **LawnGrass** – Класс, представляющий газонную траву как товар  
- **Smartphone** – Класс, представляющий смартфон как товар

## Установка:

1: Установите зависимости:
```
pip install -r requirements.txt
```
